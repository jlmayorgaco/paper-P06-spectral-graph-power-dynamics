\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This dissertation develops an operator-valued theory of dynamic grid strength
for converter-rich power systems. The central claim is that grid strength is
not a scalar such as short-circuit ratio, algebraic connectivity, or a single
damping ratio. It is a port-dependent dynamic operator whose static limit is
encoded by graph stiffness, whose oscillatory behavior is carried by the Green
function of a quadratic or rational eigenvalue problem, whose
controller-mediated behavior is represented by rational self-energy, whose
fragility is measured by structured pseudospectra, and whose nonlinear
extension appears as memory. In the classical swing-equation model,
\[
  M\ddot\theta+D\dot\theta+L\theta=p
\]
the damping matrix \(D\) is fixed. Exact graph-mode decoupling occurs when the
inertia-normalized stiffness and damping matrices commute. The special case
\(D=\gamma M\) is therefore not the whole decouplable class; it is the uniform
damping-to-inertia case in which all underdamped modes share the same real
decay rate. Rayleigh damping \(D=\alpha M+\beta L\), and more generally
commuting damping operators, define a broader constant-\(D\) floor. If \(D\) is
fixed but non-commuting, the modal damping matrix
\(Q^TM^{-1/2}DM^{-1/2}Q\) is not diagonal; graph eigenvectors still organize
stiffness, but they no longer diagonalize damping. If converter, phase-locked
loop, exciter, governor, stabilizer, or auxiliary control states are condensed,
the reduced object is not a fixed-coefficient quadratic eigenvalue problem. It
is a rational nonlinear eigenvalue problem,
\[
  T(s)=s^2M+sD_0+L+\Pi(s).
\]
Only after the rational correction is separated into
\(\Pi(s)=\Pi_K(s)+s\Pi_D(s)\) does the damping-channel specialization
\(\Sigma(s)=D_0+\Pi_D(s)\) appear.

The original contribution is not a new Laplacian metric or a new eigenvalue
solver. It is a mechanism-resolved operator framework showing when
graph-theoretic strength is a valid damping certificate, when
damping-to-inertia roughness creates modal coupling, when topology actions
must be evaluated through spectral effective resistance, and when controller
self-energy can reverse the dynamic effect predicted by static graph screens.

The thesis is deliberately theoretical and is organized as a doctoral
monograph rather than as an extended article. It develops the physical
framework, mathematical foundations, state of the art, operational graph
dynamics, constant-damping theory, rational self-energy, nonlinear memory, and
applications as separable modules.
Its unifying object is the
dynamic Green function \(G_T(s)=T(s)^{-1}\). For a line \(e=(i,j)\), the scalar
\(\mathcal R_e(s)=a_e^TG_T(s)a_e\), with \(a_e=e_i-e_j\), is a dynamic
effective resistance: at \(s=0\) it recovers classical graph effective
resistance, while away from zero it records inertia, damping, stiffness,
controller poles, residues, non-normality, and modal coupling. A finite line
action then satisfies the exact scalar equation
\(1+\Delta b_e\mathcal R_e(s)=0\); general low-rank actions satisfy the
operator determinant law
\(\det T_u(s)=\det T(s)\det[I+K_u(s)V^*T(s)^{-1}U]\). These identities turn
local eigenvalue sensitivities into first-order limits of exact finite-action
laws. The remaining modules add port-equivalence of self-energy,
model-adequacy certificates, structured fragility radii, directional
passivity, data-identified self-energy, and nonlinear memory. Simulation cases
and internal project drafts are treated as validation gates and traceability
records, not as universal theorems. The main contribution is a coherent
mathematical language for deciding when spectral graph intuition is a
certificate, when it is only a screen, when a network improvement can reduce a
dynamic margin, and when controller-aware rational self-energy or nonlinear
memory is required.

\textbf{Keywords:} operator-valued grid strength, operational graph,
graph-time resonance, dynamic effective resistance, Green function, damping
ratio, inverter-based resources, quadratic eigenvalue problem, Schur
complement, nonlinear eigenvalue problem, rational self-energy, structured
pseudospectrum, dynamic hosting capacity, virtual inertia, Braess-like
reversal, weak nodes, weak links, hidden damping margin, risk vector, ANDES,
IEEE 39-bus system.

\chapter*{Scope and Reproducibility Statement}
\addcontentsline{toc}{chapter}{Scope and Reproducibility Statement}
This document treats the current PDF as version 0 of the intellectual map, not
as a manuscript to be enlarged linearly. It is a doctoral theoretical draft,
not an experimental report. It does not present a final benchmark, a calibrated
IEEE test case, or a claim of empirical closure. Its purpose is to establish
the modular mathematical structure that later numerical experiments must
respect. Claims about constant damping, non-commuting modal coupling, Schur
condensation, rational self-energy, and nonlinear memory are presented as
theoretical statements, derivations, or chapter contracts. Claims about
practical planning are formulated as requirements for future validation.

All source files for this manuscript are kept under \texttt{reports/thesis/}.
The compiled PDF is copied to \texttt{outputs/pdf/thesis\_draft.pdf}. Scratch
material in \texttt{temp/} is preserved as historical context and is not part of
the theoretical thesis source. The integrated claim ledger is kept out of the
main scientific narrative and appears as an appendix-level traceability record.
