# ref_geometry_20261006 (geometry only)
LaTeX (LuaLaTeX + TikZ) reproduction of the visual geometry of `resources2/Póster científico_ más allá de la amortiguación nodal.png`.
Page 36 x 42 in. Coordinates in `main.tex` are reference pixels (1161 x 1355); `refstyle.tex` holds colours, fonts and reusable macros
(RefPanel, GoldNumber, TintBox/EquationCallout/GreenCallout/WarningNote, ProvedTag/ObservedTag/ProposedTag, skyline and footer art).
Panels 1-12 are empty. `build.ps1` compiles and compares; `compare.py` writes compare_overlay.png and compare_side_by_side.png.
Logos/QR: reports/poster/ias2026/assets (resources2 only contains reference images and the dossier PDF).
