\medskip
\noindent\textbf{Statement.} Four preregistered campaigns attempted an EMT corroboration of the IEEE-39 results.
\begin{itemize}
\item The first three stopped at infrastructure or measurement gates.
\item The final, task-specific qualification campaign froze the estimator and the model interfaces in advance.
It tested the estimator on a fresh blind synthetic set derived from the frozen phasor models of the actual scientific domain.
\item The estimator made no wrong-sign call. It did not reach the preregistered resolution and accuracy targets.
The failures concentrate where the target mode is a minority mode beside a dominant, similarly damped neighbouring mode family.
\item By the preregistered rule, the ParaEMT line stopped before any blind device or portfolio holdout was simulated.
\end{itemize}
No EMT evidence for or against the portfolio, policy or design claims exists.
None of the four failures is described as invalid.

\section{SQ1-2 --- blind synthetic qualification (seed 20260913)}
\textbf{Generator.} Each case takes a random library template.
\begin{itemize}
\item The template keeps its residues, perturbed by $\times U(0.8,1.25)$ and $e^{jU(-0.2,0.2)}$, and all of its nuisance modes.
\item The target is redrawn from the domain.
\item Affine trends and noise are added, with $\sigma=\nu\cdot$rms and $\nu\sim\log U[10^{-4},3\cdot10^{-3}]$.
\item $f_\text{pred}=f+U(\pm0.03)$.

\noindent\textbf{Reading.}
\begin{itemize}
\item The frozen estimator is a single-mode targeted tracker, as the V3 preregistration specified.
\item \textbf{Isolated or dominant target:} resolution $\approx96.5\,\%$, with no wrong sign.
Accuracy is marginal: p95 0.0056\sinv{}, against the 0.005 target.
\item \textbf{Minority target} beside a dominant, similarly damped mode 0.26\,Hz away:
\begin{itemize}
\item the estimator cannot isolate the target within the effective record length;
\item the jackknife guard withholds most of these cases (UNRESOLVED);
\item the remaining cases are biased.
\end{itemize}
\item This is exactly the structure of about half the EMT05 P4 subsets.
The failure is therefore \emph{task-relevant, not an artefact}: an EMT05 run with this instrument could not have established $H_\text{EMT}(P4)=\{\{30,33,35,37\}\}$.
\item \textbf{Stress strata:} ST1 20/20. ST2 0/15, with no wrong sign: the CI is too wide for strongly damped multichannel modes.
\end{itemize}
