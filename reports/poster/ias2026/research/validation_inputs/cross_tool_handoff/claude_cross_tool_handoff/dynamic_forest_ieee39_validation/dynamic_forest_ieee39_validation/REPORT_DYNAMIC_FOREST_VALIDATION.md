# Dynamic forest / network-closure validation before the final ANDES run

## Executive result

The graph/network idea survives, but not as a simple path or cycle story. The exact full-order portfolio term factorizes into a **local replacement/self-energy factor** and a **network response minor**. The response minor has an exact rooted-forest interpretation on the grounded rectangular-coordinate graph. Neither local device dynamics nor network geometry alone identifies dangerous portfolios well; their **frequency-dependent collective closure** does.

## Exact grounded dynamic-forest identity

For any nonsingular bus-coordinate operator `T(s)`, introduce a ground node and directed weights `w_ij=-T_ij` for `i!=j`, with `w_i0=sum_j T_ij`. The reduced row-Laplacian is exactly `T`. The directed matrix-tree/all-minors theorem and Jacobi's complementary-minor identity give

`det K_I = det T[I^c,I^c] / det T = Z_F(I) / Z_T`,

where `K_I=(T^-1)[I,I]`, `Z_T` is the complex spanning-tree partition function and `Z_F(I)` the rooted-forest partition function.

Python stress test on random complex directed graphs:
- maximum tree-determinant error: **1.02e-15**
- maximum rooted-forest minor error: **6.07e-16**

## Self-energy x network geometry

For a coalition `I`, `M_I=DeltaY_I K_I`; since `DeltaY_I` is block diagonal,

`det M_I = det(DeltaY_I) * Z_F(I) / Z_T`.

Across the ten frozen IEEE-39 boundaries:
- max Jacobi / forest-ratio error: **1.96e-13**
- max `det M - det DeltaY det K` relative error: **5.32e-15**

The off-diagonal 2x2 bus blocks are exactly complex-linear (max residual **0.0e+00**). The diagonal dynamic blocks are not exactly complex-scalar (median residual **0.015**) because active device/control self-energies are anisotropic. Therefore the exact simple forest theorem is on the doubled rectangular-coordinate graph; a scalar physical-bus grove formula is not claimed without a separate matrix-weighted theorem.

## Topology alone is not enough

For 125 oscillatory size-4 IEEE-39 portfolios at the reference policy, orientation-free diagnostic ROC AUC is:

| diagnostic quantity | AUC |
|---|---:|
| local self-energy factor | 0.662 |
| network forest factor alone | 0.501 |
| **full-order local x network factor** | **0.808** |
| displaced active dispatch | 0.571 |

The factor is evaluated at each portfolio's critical oscillatory frequency, so this is diagnostic evidence, not a blind prescreening benchmark. The result is that neither local replacement dynamics nor network topology alone explains the portfolio; the collective product is substantially more informative.

## Physical-line diagnosis and design

For branch-strength parameter `gamma_e`, the network-forest contrast `d log det(K_I)/d log(gamma_e)` is exact but is not sufficient by itself as a causal stability score. On the flagship boundary:
- static edge betweenness vs `|d alpha/d gamma_e|`: rho = **-0.085**
- reactance-weighted betweenness: rho = **-0.059**
- forest-leverage magnitude: rho = **0.383**

The correct design quantity is the full boundary derivative

`ds*/d gamma_e = -(p^H Q_gamma q)/(p^H Q_s q)`.

With an artificially frozen equilibrium it agrees only moderately with the re-equilibrated DAE (rho = **0.615**, sign agreement **80.4%**). The equilibrium shift matters.

Recomputing the port model after re-equilibration gives a very strong diagnostic. Across 12 targeted lines plus a 12-line random holdout (seed 20260911):
- Spearman rank correlation with full-DAE `d alpha/d gamma_e`: **1.000**
- sign agreement: **100.0%**
- median relative complex derivative error: **0.335%**
- worst relative error: **1.339%**

Thus the reduced port operator can rank whether strengthening a physical branch moves the critical mode left or right and by how much.

## What survived / what did not

Survived:
1. exact network interpretation through grounded complex forests;
2. exact self-energy x network-response factorization of the full-order interaction;
3. frequency-dependent branch diagnosis/design through the port boundary derivative;
4. independent random-holdout agreement between port and full re-equilibrated DAE line sensitivities.

Not supported as headline claims:
1. a single dominant path/cycle explanation;
2. static graph centrality as risk score;
3. forest-leverage magnitude alone as reinforcement ranking;
4. an exact scalar forest formula directly on physical buses despite anisotropic 2x2 device blocks.

**Best supported interpretation:** local replacement self-energies and network geometry are individually insufficient. Dynamic incompatibility is generated by their frequency-dependent closure.
