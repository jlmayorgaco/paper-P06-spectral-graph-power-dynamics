# Second-Model Holdout Specification

The second model must be an independently sourced GFL implementation, not a GFM holdout and not a retuned copy of the frozen Python model. Before reveal, freeze the converter identity, equilibrium procedure, candidate portfolio family, policy, and classification metric in `prereg/blind_predictions.json`.

If the second implementation cannot be instantiated or its equilibrium gate fails, classify the phase `STOPPED_BY_GATE` and report the missing evidence. A different blocker is scientifically useful; it must not be forced to match H4.

The completed SimpleGFLDC census is scoped to matched scheduled P/Q on the
common 100-MVA system base; `matched_rating=false` and
`rating_equivalence_established=false`. The follow-up PLL/current bandwidth
search uses scales 0.125, 0.5, 1, 2, and 8 on the proper three-target and
four-target portfolios. All 20 initialized representative cases are stable,
so the mixed-class holdout phase is stopped by a negative search result.
