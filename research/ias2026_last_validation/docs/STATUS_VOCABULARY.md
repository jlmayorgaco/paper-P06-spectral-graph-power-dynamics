# Final-closure status vocabulary

The final dashboard uses only these statuses:

- `PASS`
- `NUMERICALLY_VERIFIED`
- `SAME_MODEL_CROSS_CODE_VALIDATED`
- `SECOND_MODEL_VALIDATED`
- `BLIND_HOLDOUT`
- `NEGATIVE_HOLDOUT`
- `STOPPED_BY_GATE`
- `NOT_TESTED`
- `RETROSPECTIVE`
- `COMPONENT_EXECUTION_PASS`

Legacy report labels from the corrective campaign remain as provenance, but
they are not used to adjudicate the final closure gates.
