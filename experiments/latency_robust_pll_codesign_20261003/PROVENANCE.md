# Model provenance and frozen definitions

The experiment uses git HEAD `d0fecb3264aeb855ab6700fc6ef66120d4b6c33c` in a **pre-existing dirty working tree**. No commit or push was made. Exact source SHA-256 hashes, the two identical ρ vectors, gain limits, event set, and security thresholds are frozen in `EXPERIMENT_MANIFEST.json`. Existing experiment results and model files are read-only inputs; all new outputs are in this directory.

`POSTRUN_SOURCE_SNAPSHOT.json` and `source_snapshot/` additionally preserve 30 project/manifest and transitive model-source files as they existed after the numerical runs. This post-run snapshot improves portability but does not change the pre-run frozen manifest or retrospectively certify inputs that were not hashed there.
`POSTRUN_INPUT_SNAPSHOT.json` and `input_snapshot/` likewise preserve six network and operating-point CSV inputs read by the model.

Runtime: Julia **1.11.9** with the checked-in project/manifest; PowerDynamics **5.0.0**, NetworkDynamics **1.3.0**, OrdinaryDiffEqRosenbrock **2.7.1**, SciMLBase **3.53.2**, CSV **0.10.17**, DataFrames **1.8.2**, ForwardDiff **1.4.6**. Python **3.13.9** with NumPy **2.3.5**, SciPy **1.16.3**, Matplotlib **3.10.6**. DDE calculations are Float64/ComplexF64, not interval arithmetic.

Design Z is copied byte-for-byte from `../analytical_delay_codesign_mega_20261002/M1_ZERO_DELAY_DESIGN.toml`; Design N is copied from `../optimal_latency_margin_20261002/fixed_gain_designs/rho_04.toml`. Both have exactly the same nodal replacement vector at **88.45514078456176%** of initialized generator dispatch; only Kp/Ki differ. The physical source model and PLL measurement-error delay channel are defined in `../delay_dressed_replacement_frontier_20261002/DelayCharacteristic.jl` and `../nonlinear_codesign_20261001/ReducedDAE.jl`. The full descriptor action identity and contour oracle come from the earlier `q56_validate_action_space.jl` and `m3_a_trace_integral.jl`; this experiment recomputes its own L0 margins and L1 rank tests.

The frozen gain box is \(0.25(10\pi)\le K_p\le4(10\pi)\) and \(0.25(10\pi)^2/4\le K_i\le4(10\pi)^2/4\), componentwise. The spectral limit is \(\alpha\le-0.05\,\mathrm{s}^{-1}\) at zero delay and for the reported delayed boundary. The five external events are bus 8 −100 MW, bus 16 +100/−100 MW, and bus 29 +100/−100 MW, each simulated for 61 seconds. Frequency and RoCoF use the same 0.5-second observation window as the source validator. Limits: maximum |Δf| 0.5 Hz, maximum |RoCoF| 0.5 Hz/s, voltage 0.9–1.1 pu, SG actuator fractional slack at least 0.002, plus established equilibrium/guard checks. Current/Vdc metrics are recorded but not assigned unmodeled safety limits.

The DDE root oracle counts roots of the model's exponential characteristic, using a balanced ten-channel return-ratio determinant, trace integral, and independent phase winding. A count is SAFE/UNSAFE only when diagnostics agree; unresolved quadrature is INDETERMINATE. Full-contour safe/unsafe brackets accompany every accepted spectral crossing. A local crossing estimated from a continued simple root is reported as such, not a certified global first delay. Positive-delay nonlinear events are outside this experiment's validation scope.
