# All-site placement check

Before computing the new co-design results, extend the two preregistered
single-site +1ms cases to all ten buses30...39. Every case has the same delay
multiset and every site is reported. This addition was motivated by signed
weights seen in a preliminary structural calculation, so it is exploratory,
not an independent confirmation of a preregistered spatial hypothesis.
No event, gain bound, replacement, or pass threshold changes.
