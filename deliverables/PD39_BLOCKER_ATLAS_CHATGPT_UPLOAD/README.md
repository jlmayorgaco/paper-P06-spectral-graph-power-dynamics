# PD39 blocker-atlas upload package

This package contains the final narrow campaign and the prior 255+1 census
needed to interpret it. The current campaign is the `PD39_BLOCKER_ATLAS_*`
set. Files named `PD39_255PLUS1_*` are prior authoritative context and must
not be confused with new results.

Headline: CASE C - STOP. Three default-path C12 blocker candidates were not
physically confirmed. Gate A was path-sensitive and Gate B returned MaxIters
for all three C12 candidates. The atlas was not run.

Start with:

1. `PD39_BLOCKER_ATLAS_FINAL_REPORT.pdf`
2. `PD39_BLOCKER_ATLAS_CHATGPT_HANDOFF.md`
3. `PD39_BLOCKER_ATLAS_HEADLINE.json`
4. `PD39_BLOCKER_ATLAS_MASTER_CLAIMS.csv`
5. `PD39_BLOCKER_ATLAS_MASTER_CASES.csv`

Raw TDS traces are under `traces/`; current STOP figures are under `figures/`.
