# E05D stress endpoints

The EMPTY-coalition baseline is physically/eigen numerically valid for 8/8 seeds, but its actual minimum-damping 0.1--30 Hz oscillatory mode has ζ=0.0416536--0.0452751, already below the immutable 5% screen at κ=1. Therefore no admissible κ_end>=1 exists and zero coalition outcomes were inspected.

`kappa_end` is undefined, not 1.0: calling κ=1 a maximum-stress endpoint would falsely imply a weakened-grid path.
