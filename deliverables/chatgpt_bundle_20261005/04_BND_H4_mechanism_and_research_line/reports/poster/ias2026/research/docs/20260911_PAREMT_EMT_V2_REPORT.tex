\section{Diagnosis (post hoc)}

\paragraph{DV2-1: the physical ringdown agrees; the failure is in the estimator.}
\begin{itemize}
\item The frozen \texttt{matrix\_pencil} reports \textbf{resolved = False} in all
  four evaluations: both cases, EMT and reference alike.
\item Its reconstruction residual is 0.9987--0.9989, with model order 10 or 16.
\item On B-SG36 it selects a spurious growing mode, $\alpha\approx+6.3$\sinv,
  for the reference and the EMT run alike. That mode is not physical: the
  trajectories decay.
\end{itemize}

An independent fixed-order damped-sinusoid fit of $\omega-1$ over $[1.2,10]$\,s
gives:

\toprule

\midrule
R-SG30 & $-0.1182316$ & $-0.1182316$ & 1.177050 Hz\\
B-SG36 & $-0.2439564$ & $-0.2439563$ & 1.250783 Hz\\
\bottomrule

\medskip
\noindent EMT and the reference agree on the physical mode to about
$10^{-7}$\sinv. The sub-check failed because the frozen estimator is
unresolved, which the preregistered G3a rule did not require it to be. It did not
fail because of a model discrepancy.
\begin{itemize}
\item \textbf{v1.} The v1 EMT02 ringdown ``agreement'' came from the same
  unresolved estimator; its value there happened to be the physical one.
\item \textbf{V2.} ``Where resolved'' logic was preregistered only for the G4b
  estimator R. G3a keeps the unconditional v1 rule and is judged by it.
\end{itemize}

\paragraph{DV2-2: the frozen estimator on synthetic multi-channel data.} The
input imitates EMT05--EMT18: 20 channels, 30 s, a target mode plus a damped
0.95-Hz mode, and the pulse at 1 s.

\medskip

\toprule

\medskip
\paragraph{Mechanism.} The model order comes from the singular-value threshold
$10^{-4}$, and it admits spurious modes with $|z|\gg1$. \texttt{z**k} then
overflows in the least-squares residue fit, which gives inf, then NaN, then an
SVD failure. When it does not crash, the spurious columns drive the residual to
about 1, so the case is never ``resolved''.

\paragraph{Consequence.} Estimator A was frozen in v1 \S5 and reused unchanged in
V2, and its $\alpha_A$ is the reported $\alpha_{\rm EMT}$. It could not have
produced a STABLE/UNSTABLE verdict for EMT05--EMT18 even if every device gate had
passed. This is a defect of the frozen v1 design, found only now, and under the
rules it is not repaired inside V2.

\section{For the author: what a V3 would need}

This is a decision memo, not executed.
\begin{enumerate}
\item \textbf{Replace or repair estimator A before any use.} Freeze a numerically
  safe pencil and pre-validate it on known signals, then commit the validation
  before any TX4 EMT result.
  \begin{itemize}
  \item \emph{Validation set:} synthetic multi-channel signals (including
    DV2-2), and the frozen phasor TDS of P4 H4 and $G_S$, where it must reproduce
    the frozen eigenvalues.
  \item \emph{Example safeguards:} scaled residue evaluation, a model order fixed
    by an information criterion, and spurious-mode rejection.
  \end{itemize}
\item \textbf{SG ringdown sub-check.} Condition it on the estimator being
  resolved, or use a preregistered fixed-order fit. Keep the 2\,\% trajectory
  rule unchanged.
\item \textbf{Blind SG holdout.} B-SG36 has now been seen, so a V3 needs a new
  one. The GFL holdouts B1-GFL35 and B2-GFL37 are still blind and can be kept.
\item \textbf{Everything else unchanged:} the V2 interface, derivation and G4b
  checks; EMT04--EMT18, their frozen predictions and their success rules.
\item \textbf{Stop rule unchanged.} If the voltage interface fails G4b on the
  blind holdouts, STOP. There is no other interface in the same campaign.
\end{enumerate}
