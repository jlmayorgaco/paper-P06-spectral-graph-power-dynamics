\begin{itemize}

\item \textbf{B-SG36.} The EMT run and its reference share the same spurious

\item \textbf{DV2-2.} Three LinAlgError crashes and one unresolved case.
\item \textbf{Mechanism:}
  \begin{itemize}
  \item spurious $|z|$ up to 18.9;
  \item the full-record Vandermonde $z^k$ spans $10^{26}$--$10^{95}$, or
    overflows ($10^{355}$);
  \item \texttt{lstsq} keeps rank 1--3 of 10--16;
  \item the $\exp(2\alpha T)$ energy weight ($10^{43}$) selects a spurious
    mode with a residue of $10^{-22}$.
  \end{itemize}
\end{itemize}

\section{The V3 instrument (prereg \texttt{6d339006}; amendment V3-AM1)}

\paragraph{Estimator.} A new multi-channel bounded variable-projection damped-mode
estimator.
\begin{itemize}
\item \textbf{Model.} For each channel, one damped mode plus an affine term,
  with time centred on the window.
\item \textbf{Data.} 0.1-s block means, which leave every exponential's $s$
  unchanged.
\item \textbf{Fit.} One Householder QR of a common 4-column design matrix. Only
  $(\alpha,f)$ are optimized, within bounds.
\item \textbf{Uncertainty and decision.}
  \begin{itemize}
  \item channel and time-block jackknife CI;
  \item resolved flag R1--R4;
  \item verdict from the CI with EPS $=0.002$;
  \item targeted tracker (committed $f_{\rm pred}\pm0.15$\,Hz; $\alpha_{\rm pred}$
    never used);
  \item broad-band sentinel;
  \item adaptive run length 30 $\to$ 60 $\to$ 90\,s.
  \end{itemize}
\item \textbf{Removed.} There is no full-record Vandermonde and no exponential
  energy weighting.
\end{itemize}

\paragraph{V3-AM1,} committed \emph{before} any blind data existed.
\begin{itemize}
\item \textbf{Problem.} On the development data (seed 1111, DV2-2, the
  non-holdout TDS P4 BASE), the unweighted fit carried a nuisance-mode bias of
  0.0055 on DV2-2. It also left one strongly damped S6 development case
  unresolved.
\item \textbf{Change.} An envelope-equalizing weight $\exp(-\alpha_w\tau)$, with
  $|\alpha_w|\le3/L$, taken from a first unweighted pass and then fixed. The
  optimization is still over $(\alpha,f)$ only, and no criterion was changed.
\item \textbf{Development result:}
  \begin{itemize}
  \item DV2-2 bias 0.00036;
  \item S6 5/5 on the development set;
  \item development TDS $\Delta\alpha=5.6\times10^{-4}$ against the linear
    eigenvalue.
  \end{itemize}
\end{itemize}

\paragraph{The failing case.} S6 \#137 has $\alpha_{\rm true}=-0.473$\sinv{} and
$f=1.067$\,Hz, a single channel with a slow real mode superposed, in the window
$[1.5,10]$\,s.
\begin{itemize}
\item The estimate was $\hat\alpha=-0.455$.
\item The time-block jackknife CI half-width was $0.027$\sinv, above the
  $0.02$ limit (R4), with a median residual of 0.26.
\item The instrument reported \textbf{UNRESOLVED instead of a biased value}.
\item The criterion nevertheless requires all 15 cases to resolve.
\end{itemize}
The unresolved S4 and S5 cases also had biased point estimates (e.g.\
$-0.419$ against $-0.262$), and each was withheld as UNRESOLVED, never reported
as a value.

\section{For the author (decision memo; nothing executed)}

\paragraph{What V3 established about the instrument.} The new VP estimator does
not crash, gives no wrong-sign verdict, and is accurate to p95 0.004\sinv. Where
it cannot separate modes, it withholds a value rather than report a biased one.
This is instrument evidence only.

\paragraph{Why V3 stopped.} The preregistered criterion demanded that all 15
single-channel ringdowns resolve, and one heavily damped case did not.

\paragraph{Options.}
\begin{itemize}
\item \textbf{(a) Close the EMT line with its present record.} The network and
  operating point are EMT-reproduced (V19). Every other claim keeps its phasor
  and ANDES status. This is consistent with ``no V4 merely to obtain
  agreement''.
\item \textbf{(b) A new, separately justified campaign,} with its own
  preregistration. Its blind elements would be the unused TDS holdout T1--T9,
  B-SG38, B1-GFL35, B2-GFL37 and a fresh synthetic seed.
\end{itemize}
