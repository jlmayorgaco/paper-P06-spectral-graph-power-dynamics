\section{Executive summary}

\paragraph{Question.} Do the principal observable predictions of the frozen
phasor-domain theory survive an independent electromagnetic-transient (EMT)
realization of the \emph{same} IEEE-39 network and the \emph{same} custom
device and control equations?

\paragraph{Answer.} This campaign cannot say. Each stage stopped at a
preregistered gate:
\begin{enumerate}
\item \textbf{EMT00 (tool).} The official ParaEMT IEEE-39 case installs, runs
  deterministically, serializes and resumes.
  \begin{itemize}
  \item Its no-event run is \emph{not} stationary: a 0.62\,pu start-up jump.
  \item Cause: upstream never applies the one transformer ratio its case
    carries. With that tap applied, the jump falls to $2.2\times10^{-4}$\,pu.
  \item The tool gate was recorded as ``PASS (tool)''. The stationarity check
    as first written failed; this is disclosed in Section~\ref{sec:prov}.
  \end{itemize}
\item \textbf{EMT01 (network, G1): PASS.}
  \begin{itemize}
  \item The frozen TX4 network is built from ParaEMT's own companion elements.
  \item Its 60-Hz admittance matches the canonical Ybus to
    $1.7\times10^{-16}$.
  \item The EMT equilibrium matches the canonical power flow to
    $1.5\times10^{-6}$\,pu in $|V|$ and $5.9\times10^{-6}$\,rad in angle
    (tolerances $10^{-4}$ and $10^{-3}$).
  \item The official ParaEMT IEEE-39 differs from TX4 in 24 of 195 network
    rows, so it is not used.
  \end{itemize}
\item \textbf{EMT02 (two-axis machine, G3): FAIL.}
  \begin{itemize}
  \item Six of seven states track the phasor reference within 0.87\,\% of
    their excursion, and the ringdown agrees
    ($\Delta\alpha=-3.1\times10^{-4}$\sinv, $\Delta f=1.2\times10^{-4}$\,Hz).
  \item The AVR state $e_{fd}$ misses the 2\,\% trajectory limit: 2.26\,\%.
  \item Diagnostics (not gates) attribute the excess to the electromagnetic
    dynamics of the EMT line, a physical effect of relative size
    $f/f_0\approx2\,\%$. The machine transcription itself agrees to
    $2\times10^{-4}$.
  \end{itemize}
\item \textbf{EMT03 (11-state GFL, G4): FAIL.}
  \begin{itemize}
  \item With the preregistered EMT line, an undamped step-to-step (Nyquist)
    mode of the trapezoidal line inductance is amplified by the
    ideal-current-source converter.
  \item At $g=0$ the three runs go non-finite at 0.76\,s. At $g>0$ they stay
    finite but saturate at a 0.11\,pu alternation, giving state errors
    3--1100$\times$ the excursion.
  \item With the line realized algebraically (diagnostic only), all nine cases
    agree within 0.78\,\%.
  \end{itemize}
\item \textbf{EMT04--EMT18: BLOCKED.}
\end{enumerate}

\paragraph{What changes in the claim ledger.} Nothing is weakened or
strengthened, except that V19/I01 (network and operating point) gains an EMT
reproduction. V21/I04 (the custom-GFL results in a second simulator) keeps its
final-ledger status: VALIDATED by the independent ANDES reproduction (Phase 8).
The EMT reproduction was not achieved. \emph{(Corrected in V2-0; the first
version wrongly said ``NOT YET TESTED''.)}

\paragraph{Next step.} A preregistration v2 is proposed for the author's
decision (Appendix~A). It is not executed here.

\section{Evidence taxonomy}

Every claim receives exactly one label:
\begin{itemize}
\item THEOREM (no EMT validation required);
\item EMT CORROBORATED;
\item EMT QUANTITATIVELY REPRODUCED;
\item EMT REFUTED;
\item EMT UNRESOLVED;
\item NOT APPLICABLE TO EMT.
\end{itemize}

\paragraph{Wording.} EMT can corroborate the \emph{observable consequence} of a
theorem. It never proves one.
\begin{itemize}
\item T01--T06 and C01--C06 are not EMT targets.
\item Connected cumulants remain secondary and get no EMT figure.
\end{itemize}

In this report, ``BLOCKED'' means ``not run because a preregistered stopping
gate failed''. Its taxonomy label is EMT UNRESOLVED.

\section{Constant-power-load treatment}

\textbf{Outcome A} (declared in prereg \S3.3): an EMT-compatible
fundamental-frequency constant-power load.
\begin{itemize}
\item A constant-impedance Norton element $Y_0=\overline{S_0}/|V_0|^2$.
\item A compensating injection
  $I_{\rm comp}=-(\overline{S(t)/V_f}-Y_0V_f)$, where $V_f$ is a 1-ms
  first-order filter of the extracted phasor.
\item The incremental admittance is $Y_0+(Y_{\rm cp}-Y_0)/(1+s\tau_m)$: exact
  constant power as $s\tau_m\to0$, with a relative deviation of
  $4.4\times10^{-3}$ at 0.7\,Hz.
\end{itemize}
There is no silent substitution; the stock RLC load is not used.

\begin{itemize}
\item \textbf{Equilibrium with the CP load.} Reproduced in EMT01: PASS.
\item \textbf{Low-frequency equivalence} ($\tau_m$ 0.5\,ms vs 1\,ms holdout,
  EMT04 acceptance; gate G2). Not run: \blocked.
\end{itemize}

\noindent\textbf{Gate G4: FAIL.}

\paragraph{Diagnostics.} See Figure~\ref{fig:fd2}.
\begin{itemize}
\item \textbf{D4, mechanism.} With no disturbance, the step-to-step
  alternation of $|V_T|$ grows:
  \begin{itemize}
  \item at $g=0$: exponentially at 26.6\sinv{} (factor 1.0013 per step) until
    the run fails;
  \item at $g=0.25$: at 445\sinv, saturating at about 0.11\,pu by 0.1\,s.
  \item Reading: an ideal current source feeding a lossless trapezoidal
    inductor has an undamped Nyquist mode, and the explicitly coupled
    converter loop amplifies it.
  \end{itemize}
\item \textbf{D1, transcription.} With the line algebraic, all nine cases are
  finite and every state is within 0.78\,\% of its excursion. The
  transcription is correct; the failure is in the EMT interface.
\item \textbf{D5, IEEE-39.} No-event 30-s runs of the preregistered
  realization: P4 base, P4 H4, and H4 at $G_S$.
  \begin{itemize}
  \item The start-up alternation at the four GFL buses ($5\times10^{-6}$\,pu)
    decays to $2\times10^{-8}$ (P4 H4) and $7\times10^{-9}$\,pu ($G_S$ H4)
    over 1--10\,s. No step-to-step instability develops.
  \item In P4 H4 over 10--30\,s, the consecutive-sample difference rises to
    $2.4\times10^{-7}$\,pu, together with a slow $|V|$ drift of

\section{Limitations}
\begin{itemize}
\item \textbf{Diagnostics are post hoc.} D1--D5 were designed after the gate
  failures. They explain the failures; they do not replace the gates.
\item \textbf{The unit-test system is part of the preregistration.} A lossless
  line to a stiff source is a demanding topology for an ideal current source.
  D5 shows the IEEE-39 GFL buses behave differently, but the test was chosen
  in advance and failed.
\item \textbf{The GFL interface is a design choice.} It is an average-value
  ideal current source with explicit predictor--corrector coupling. Other
  interfaces were not preregistered and were not tried as a gate:
  \begin{itemize}
  \item a converter voltage behind an EMT filter branch;
  \item Norton-compensated injection;
  \item ParaEMT's standard numerical damping.
  \end{itemize}
\item \textbf{A domain-crossing comparison.} The 2\,\% trajectory rule
  compares a quasi-static phasor reference with an EMT network. The network's
  own electromagnetic dynamics contribute about $f/f_0$ of the excursion.
\item \textbf{Scope of EMT01.} It covers the base portfolio at P4 only; the
  GFL equilibrium in IEEE-39 was not gated.
\end{itemize}
