   python experiments/poster_julia_validation_20261003/restore_inputs.py
   This adds missing byte-identical inputs and refuses to overwrite differences.
   It deliberately preserves the current article and root Julia environment.
   The Julia project used here is included in the historical source archive:
   experiments/physical_collective_damping_20261003/source_snapshot/

   Python 3.13.9; numpy 2.3.5; scipy 1.16.3; pandas 2.3.3;
   matplotlib 3.10.6; Pillow; qrcode 8.2.
   qrcode was installed only in the new poster's build/vendor directory.
   Install dependencies into your chosen environment; no vendor tree is archived.

   python experiments/poster_julia_validation_20261003/check_rank_law.py
   This writes all 60 direct Schur-versus-rank-one comparisons.

   Julia 1.11.9; use the supplied Project.toml / Manifest.toml.
   Instantiate that environment first if needed. No delay or gain optimization.
   Outputs are in this directory, not in the frozen historical experiment.

   python experiments/poster_julia_validation_20261003/close_article.py

   for focused editing. The print file is 36 x 48 inches, portrait.
