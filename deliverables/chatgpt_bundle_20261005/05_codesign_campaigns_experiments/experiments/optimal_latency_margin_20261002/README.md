# Optimal latency margin versus SG→GFL replacement — targeted test

This directory tests the preregistered question in the attached *FINAL TARGETED EXPERIMENT* protocol. The decisive result is **negative for the proposed replacement–latency headline on the tested IEEE-39 path**. An exact-characteristic numerical DDE contour reproduces a fast PLL root-cluster transition near 37–40 ms. Yet, at fixed nominal PLL gains, raising GFL replacement from 87.5% to 88.45514% changes the locally tracked latency crossing by only **+0.00343 ms**; all five points fall in the same full-contour bracket, [39.375, 39.453125] ms. This is below the protocol's 2 ms materiality threshold. The gain-optimization and inverse-frontier stages were therefore stopped.

The two previously stored designs cross at **39.38022 ms** (87.5%) and **37.38705 ms** (88.45514%). Their 1.99316 ms difference combines a change in nodal replacement with a change in nodal gains. At the high replacement vector, swapping the stored zero-delay-tuned gains for the in-bounds seed nominal gains raises the local crossing to **39.38366 ms**: an observed gain-vector comparison, **not** an optimum or a delayed-event-safe design. This separates the gain effect from the replacement-only path.

The numerical root count uses the exact delay exponentials of the linearized model and an action-space return ratio. “Exact characteristic” describes the modeled equation; the Float64 contour/root solutions are numerical, not interval-certified. A first observed crossing on the swept interval is not a proof of the global infimum over every positive delay. No positive-delay nonlinear event simulations were run, so these margins do not establish delayed event safety.
