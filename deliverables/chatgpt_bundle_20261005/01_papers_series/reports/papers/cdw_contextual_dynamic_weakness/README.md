# Portfolio-Conditioned Dynamic Reinforcement Ranking in Inverter-Rich Power Networks: Evidence from Two Benchmarks

This is the IEEE Transactions on Power Systems manuscript of the CDW line, written in the IEEEtran journal class. It combines the CDW hardening campaign (IEEE 39-bus) with the confirmatory IEEE 68-bus replication (branch `research/cdw-ieee68-replication`).

The replication's preregistered rule gave CASE B, and the title and contributions were pivoted after that decision. The ranking method is the headline; contextual reversal is IEEE-39 benchmark-specific evidence.

## Files

| file | content |
|---|---|
| `main.tex` | manuscript |
| `cdw_numbers.tex` | every number quoted in the text as a macro, generated from the result files by `experiments/cdw_hardening/CDWH_NUMBERS.py` |
| `cdw68_numbers.tex`, `tab_cdw68.tex` | IEEE-68 numbers and table, generated by `ieee68_replication/code/R23_paper_numbers.py` |
| `tab_*.tex` | result tables, generated by `CDWH_TABLES.py` |
| `sec_corridors.tex` | corridor subsection (equal budget and size-matched null), generated after H10 |
| `references.bib` | bibliography; each DOI entry was fetched from Crossref by `CDWH_BIB.py` |
| `supplement.tex` | supplementary material, generated by `CDWH_SUPPLEMENT.py` |
| `figures/` | vector figures (`CDWH_F*`: main text; `CDWH_S*`: supplement; `CDW68_F*`: IEEE-68, copied from `ieee68_replication/figures/`) |

All generator scripts live in
`reports/poster/ias2026/research/contextual_dynamic_weakness/experiments/cdw_hardening/`.

## Build

MiKTeX, with no Perl needed:

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
pdflatex supplement && pdflatex supplement
```

## Regenerate numbers, tables and figures

Run with `.venv/tx3-analysis`:

```
python CDWH_NUMBERS.py; python CDWH_TABLES.py; python CDWH_FIGURES.py; python CDWH_SUPPLEMENT.py
python CDWH_BIB.py   # optional: refetch Crossref metadata (sends DOIs only)
```
