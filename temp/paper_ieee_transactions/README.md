# IEEE Transactions Paper Package

Working title:

**Controller-Aware Rational Self-Energy for Damping-Margin Analysis of IBR Grids**

This folder contains an IEEE Transactions-style LaTeX manuscript package.

The intended contribution is methodological/applied for power systems:
established tools from Schur complements, rational nonlinear eigenvalue
problems, contour eigensolvers, second-order systems, QEP sensitivity, spectral
graph theory, and eigenvalue perturbation are reorganized into a
controller-aware damping-margin bridge for heterogeneous IBR grids. The current
headline claim is the failure of a static scalar bridge and the corresponding
rational self-energy bridge that preserves controller-mediated damping
mechanisms. The closed-form second-order correction is an interpretable
estimator component that still requires registered full-ANDES comparison before
it can become the submission headline.

## Build

From this folder:

```powershell
.\compile.ps1
```

or manually:

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

The manuscript uses the installed IEEEtran class:

```latex
\documentclass[journal]{IEEEtran}
```

## Honesty Status

This is a finalized methodological/master-thesis manuscript package, not a
final IEEE Transactions empirical submission.

The paper intentionally distinguishes:

- mathematically verified claims,
- synthetic stress-test claims,
- claims requiring IEEE 39-bus ANDES validation,
- originality claims requiring targeted literature search.

The originality target is:

- new power-system formulation: controller-aware rational self-energy as the
  reduced damping-margin object for IBR grids when static nodal damping fails,
- new diagnostic result: network-family versus control-family criticality via
  condensed-state participation, including the Mix60 PLL-family critical mode,
- new bridge-enabled mechanism: modal-local control-resonant reinforcement
  reversal with a soft-GFL negative control,
- estimator and planning uses remain secondary until Experiments A--E compare
  them against registered full-ANDES/NEP baselines.

Before journal submission, the ANDES validation tables and figures must be
completed and the bibliography must be checked against IEEE Xplore / arXiv for
the exact contribution claims.
