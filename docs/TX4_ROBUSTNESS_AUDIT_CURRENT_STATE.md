## Scope and isolation

This audit is a child worktree of the completed TX4 robustness campaign. The
source robustness branch and the frozen exact-P4/GFL11 worktree remain
unchanged. No push is authorized. The existing final paper/poster PDFs are
not treated as corrected outputs and are not used as evidence for this audit.

## Existing campaign inventory

The source campaign contains 20,590 sampled conditions and 329,440 portfolio
rows over the 16 subsets of V4={30,33,35,37}. It contains 426 all-portfolio
exact calibration conditions (6,816 rows), exact H4 rows for the remaining
conditions, and 302,460 proper-subset rows generated by an ExtraTrees
surrogate. The existing master table is available as CSV.GZ and Parquet.

The existing endpoint flags were first computed from the complete-spectrum
`alpha_all`, then overwritten by `normalize_tx4_transverse_endpoints.py` using
the 0.3–1.5 Hz `alpha_EM` band. Neither implementation enumerates the true
minimal-blocker antichain H0. Therefore the existing H4_PRESENT and EXACT_H4
columns are audit inputs only, not accepted primary truth.

The existing `eta_H4` is also derived from a proper-subset maximum rather than
from the corrected minimal-blocker definition. It will be recomputed only for
conditions with a clean exact H4 root, using the registered local singular-
value definition where the required local data are available.

## Audit decision gates

1. Locate the engineering threshold from the existing preregistration/code;
   no undocumented U005/H005 threshold will be invented.
2. Run blocker-definition unit tests before changing campaign semantics.
3. Audit the existing exact calibration and surrogate flags without rerunning.
4. Validate surrogate minimality against exact all-16 calibration truth. The
   surrogate may not be used for primary minimality unless every strict gate
   passes: zero false-minimal rows, zero missed-minimal rows, 100% exact H4,
   100% H4_PRESENT, and 100% H0-antichain agreement.
5. If the strict gate fails, evaluate the existing QMC and MC coordinates with
   the exact frozen DAE for all 16 portfolios, without changing samples or
   seeds. The exact outputs then replace surrogate rows for primary statistics.

## Current audit status

At audit start, the strict gate is not yet certified. The observed existence of
302,460 surrogate proper-subset rows means a full exact recomputation is the
prespecified fallback unless validation proves the surrogate gate completely.
